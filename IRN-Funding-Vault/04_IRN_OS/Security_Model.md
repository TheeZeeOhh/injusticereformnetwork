# Security Model

Our security posture is categorized as **InfoSec as Witchcraft (Level 3)**. We treat every digital interaction with extreme caution.

## Key Principles
1. **Zero-Trust:** No node, user, or network is implicitly trusted. All data syncs require explicit cryptographic verification.
2. **Offline-First Resilience:** The system must remain fully operational when disconnected from the global internet.
3. **Metadata Scrubbing:** Automated sanitization of EXIF data, IP logs, and identifying metadata from all uploaded evidence and communications.
4. **Deniability:** Implementation of plausible deniability protocols and panic-wipe functions to protect organizers in hostile environments.
