## 2. Local-First Model Execution & Cloud Independence (100% Local Ollama Inference)

- **100% Local Ollama Inference Mandate**: All artificial intelligence model workloads, embeddings generation, and prompt reasoning run exclusively on local edge hardware using self-hosted Ollama containers, period. No cap.
- **Zero Commercial Cloud Leaks**: Transmitting prompt data, document payloads, or user queries to external cloud APIs (such as OpenAI, Anthropic, Google, or Microsoft) is strictly prohibited across the entire codebase.
- **`nomic-embed-text` Vector Store Standard**: Document vectorization and semantic search utilize the open-source `nomic-embed-text` embedding model hosted locally at `http://localhost:11434/api/embed` or `/api/embeddings`.
- **Network Refusal Fallback Engine**: If local Ollama services become unavailable or uncommunicative, the application executes a deterministic, unit-length normalized mock vector generator to preserve app function without touching public network endpoints.
- **Ephemeral RAM Memory Boundary**: Active context windows, model KV caches, and temporary prompt vectors are restricted to volatile system memory (RAM), ensuring zero residual AI artifacts remain on persistent storage.

## 3. Algorithmic Non-Surveillance & Anti-Redlining Imperative (Rejecting Predictive Policing)

- **Total Ban on Predictive Policing**: The network strictly forbids any algorithmic model, scoring heuristic, or data pipeline designed for predictive policing, recidivism forecasting, or law enforcement threat scoring.
- **Scrubbing Digital Redlining Proxies**: AI processing pipelines automatically detect and eliminate proxy variables—including zip codes, credit scores, prior contact counts, and location history—that facilitate algorithmic redlining.
- **Counter-Surveillance Risk Defense**: Built-in algorithmic countermeasures reverse-engineer state risk scoring engines to defend grassroots organizers against stingray devices, digital surveillance, and targeted state harassment.
- **Disparate Impact Elimination**: Models undergo continuous statistical validation to guarantee that false-positive rates and algorithmic decisions introduce zero disparate impact across marginalized demographics.
- **Anti-Extraction Data Boundaries**: Models are prohibited from ingesting, tracking, or profiling community interaction patterns, preventing state actors from mapping movement networks or financial flows.

## 4. Community Data Ownership, Explicit Consent & Data Sovereignty

- **Sovereign Community Data Custody**: All training sets, prompt inputs, and generated artifacts remain the unalienable property of the community members who created them, hosted under local Zero-Trust architecture.
- **Explicit Opt-In Authorization**: No data is collected, vectorized, or analyzed by local AI models without affirmative, cryptographic opt-in consent from the data owner.
- **Right to Algorithmic Expungement**: Community members hold the immediate, irrevocable right to purge their data, embeddings, and associated Merkle-Search Trie nodes through cryptographic deletion keys.

- **Zero Third-Party Data Monetization**: Under no circumstances will community data, model outputs, or semantic index trees be sold, licensed, or shared with commercial entities, advertisers, or state watchdogs.
